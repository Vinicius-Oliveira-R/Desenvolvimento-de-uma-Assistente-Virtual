# 1. Introdução

O tema deste trabalho é o desenvolvimento de um assistente virtual inteligente para agendamento e gestão de consultas clínicas. O problema central é a necessidade de otimizar a organização da agenda médica, reduzir conflitos de disponibilidade e melhorar a comunicação com pacientes e recepcionistas por meio de uma interface natural em linguagem humana.

Em clínicas, consultórios e hospitais, a gestão de horários é uma atividade crítica. A ausência de uma organização eficiente pode gerar filas, atrasos, consultas canceladas e insatisfação de pacientes. Nesse contexto, sistemas de apoio automatizados tornam-se fundamentais para racionalizar processos e reduzir o esforço manual de coordenação.

Por isso, este trabalho propõe um protótipo funcional de sistema capaz de interpretar mensagens em linguagem natural, recuperar dados relevantes como médico, data, hora e paciente, verificar disponibilidade e recomendar opções adequadas. A solução foi implementada em Python com FastAPI, organizando a aplicação em camadas e validando o comportamento com testes automatizados.

A proposta combina diferentes áreas do conhecimento: engenharia de software, banco de dados, arquitetura de sistemas e inteligência artificial aplicada. O resultado é um projeto defensável como TCC porque integra uma base funcional real, regras de negócio relevantes para o contexto clínico e uma interface de interação inteligente em linguagem natural.
