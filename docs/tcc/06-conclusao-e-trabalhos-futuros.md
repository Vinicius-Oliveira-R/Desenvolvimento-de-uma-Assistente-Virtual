# 6. Conclusão e trabalhos futuros

## 6.1 Conclusão

Este trabalho apresentou o desenvolvimento de um assistente virtual inteligente para agendamento e gestão de consultas clínicas. A solução foi construída de forma gradual, com foco em funcionalidade, regras de negócio e validação. O resultado é um sistema executável, testável e funcional, com potencial para aplicação em cenários reais de atendimento.

A partir da modelagem do domínio clínico, implementação de API REST e regras de negócio, foi possível criar um protótipo capaz de interpretar pedidos em linguagem natural e realizar agendamentos com base em disponibilidade real.

## 6.2 Trabalhos futuros

Como continuidade natural do projeto, destacam-se as seguintes melhorias:

- integração com banco de dados PostgreSQL em produção;
- autenticação e autorização mais robustas com controle de perfis;
- melhoria da inteligência do assistente com NLP avançado;
- uso de modelos de recomendação para priorizar horários com base em histórico;
- criação de interface web para uso por pacientes e recepcionistas;
- expansão para notificações por e-mail e WhatsApp;
- integração com agenda médica e sincronização de calendário.

Essas melhorias ampliariam a maturidade do sistema e o aproximariam de uma solução realmente pronta para uso em ambiente clínico.
